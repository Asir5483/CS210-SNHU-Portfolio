Corner Grocer Item Tracker
SNHU CS-210 - Programming Languages

Files
- CornerGrocer.sln: Visual Studio solution
- CornerGrocer.vcxproj: Visual Studio C++ project (C++17)
- CornerGrocer.cpp: Program source code
- CS210_Project_Three_Input_File.txt: Required purchase-history input
- frequency.dat: Example backup output; the program recreates it at startup

To run
1. Open CornerGrocer.sln in Visual Studio.
2. Build and run the CornerGrocer project.
3. The project copies CS210_Project_Three_Input_File.txt to the build output folder.
4. At startup, the program reads the purchase history and writes frequency.dat.

The source was also compiled with g++ using C++17 and warning flags. Search,
frequency listing, histogram, exit, invalid menu input, blank search input,
and backup-file creation were tested.
